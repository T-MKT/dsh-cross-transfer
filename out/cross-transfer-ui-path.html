结论

服务端可用不等于界面可见。修复前 bundle 没有槽位注册，CrossTransferUI 虽在包里却无挂载点；修复后 apply() 注册 sidebar.footer.action，入口与浮层同时成立。

03
Browser · 槽位

apply() 注册 sidebar.footer.action

bundleHasMarker true

bundle 在浏览器执行 apply()，先注入 slots 服务，再通过 ctx.slots.inject 注册 sidebar.footer.action；CrossTransferLauncher 作为占位组件渲染侧边栏底部入口。

BUNDLE apply() inject: connection, slots
→
SLOT sidebar.footer.action id: cross-transfer-panel
→
UI ⇄ 入口 + 浮层 position: fixed 
// src/client/index.tsx:22,67-76
export const inject = ['connection', 'slots']

ctx.slots.inject('sidebar.footer.action', () =>
  ctx.slots.register(
    { name: 'sidebar.footer.action',
      id: 'cross-transfer-panel', order: 100,
      inject: () => ({ client }) },
    CrossTransferLauncher
  )
)
判定证据

浮层口径：代码只注册一个 slot（sidebar.footer.action）；浮层是 CrossTransferLauncher 在该槽位内渲染的 position:fixed 面板（role="dialog"），不是第二个 shell.overlay 注册。
